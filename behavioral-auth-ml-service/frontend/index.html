⚡ Workflow Quick Guide

  1. Step 1 (Enrollment): Select a user ID and type the enrollment passage ~20 times to build a complete baseline profile.
  2. Step 2 (Verification): Switch to the Verify tab and type the verification passage as yourself to test genuine score (should ALLOW).
  3. Step 3 (Impostor Test): Have another user type the verify passage under your user ID to trigger STEP-UP / DENY.
  4. Step 4 (Adaptive Retrain): Bank 10 high-trust sessions and test shadow model retraining.

🎯 System Health & Parameters

  • • Model Type: IsolationForest (200 trees, 0.1 contamination)
  • • Cold Start Stages: Collecting (0-9) → Provisional (10-19) → Full (20+)
  • • Decision Window: 5-sample rolling average (3 low scores = DENY)
  • • Feature Vector: 14-dim (Dwell, Flight, WPM, Backspace, 8 Digraphs)
