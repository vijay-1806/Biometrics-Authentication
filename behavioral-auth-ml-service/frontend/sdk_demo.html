📄 Embed in Any Website in 15 Lines

External developers integrate keystroke biometrics with zero API code. Just include the SDK and call startSession(): 

<!-- 1. Include the Universal BioAuth SDK script in your page -->
<script src="http://localhost:8000/sdk.js"></script>

<script>
  // 2. Initialize BioAuth with your tenant API key and candidate ID
  const bio = new BioAuth({
    apiKey: 'bio_live_your_tenant_key',
    userId: 'student_12345'
  });

  // 3. Drop-in Enrollment Modal (collects 20 samples & trains model automatically)
  bio.openEnrollmentModal({
    targetSamples: 20,
    onComplete: (res) => console.log('Model ready!', res)
  });

  // 4. Start Continuous Proctoring (SDK buffers, timing math, & calls API for you)
  bio.startSession({
    examId: 'cs101_midterm',
    onScore: (data) => console.log('Live Trust Score:', data.trust_score),
    onViolation: (v) => alert('Proctor Warning: ' + v.type)
  });
</script>
